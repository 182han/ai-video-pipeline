## 核心结论速览

- **场景**：电视屏保 / 展厅大屏，循环播放
- **风格**：B 站风光长视频（4K HDR 治愈系 + 8K 星空延时感）
- **主力模型**：Kling 3.0 原生 4K 15s（¥3/s）—— 待迭代 0 免费额度盲测确认，备选 Seedance 2.5 1080p+超分
- **架构**：核心链（必选）+ 增强层（超分/HDR/配乐可选、可补跑）
- **验收**：企业五维考察（品质/成本/效率/工程可复用/协作交付），成功率 ≥90%
