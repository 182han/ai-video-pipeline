# 云端部署与数据库接入指南

> 面向本项目（`app/` 下的 AI 长视频自动生成流水线）的实操手册。
> 配套改动见 [config.js](../app/config.js)、[src/storage/](../app/src/storage/)、[Dockerfile](../app/Dockerfile)。

---

## 一、先搞清楚：你的项目属于哪种"上云"

| 你的需求 | 能不能用静态托管 | 该用哪类平台 |
|---|---|---|
| 只想让人看演示汇报页（`docs/*.html`） | ✅ 可以 | Cloudflare Pages / Vercel / GitHub Pages |
| 想让人**真正点开用**网页 + 后端服务 | ❌ 不行 | 必须能跑 Node 容器：Hugging Face Spaces / Oracle VM / Railway |
| 只想托管代码 | — | GitHub 仓库 |

**结论**：你的项目是 Node + Express + WebSocket + FFmpeg，还调 AI 视频 API，所以**必须选第二种**。

---

## 二、推荐组合（免费）

### 方案 A：Hugging Face Spaces（最省事，推荐先用这个）

优点：免费、**不需要信用卡**、国内可直连、支持 Docker。
缺点：闲置会休眠，首次访问等 10~30 秒。

步骤：
1. 注册 https://huggingface.co
2. 新建 Space → SDK 选 **Docker** → 硬件选 **CPU basic (free)**
3. 把 [app/](../app) 目录内容推进这个 Space 的 Git 仓库
   - `Dockerfile` 已在项目里准备好，Spaces 会自动识别
   - 把 [README_HF.md](../app/README_HF.md) 改名成 `README.md` 放进 Space 根目录（它的 frontmatter 告诉 Spaces 用 Docker 且端口 3000）
4. 在 Space 的 **Settings → Variables and secrets** 里填环境变量（见下方第五节）
5. 等构建完成，访问 `https://huggingface.co/spaces/你的用户名/空间名`

### 方案 B：Oracle Cloud 永久免费 VM（最稳，能长期跑）

优点：永久免费 ARM 实例（4 核 24G）、有公网 IP、不会休眠。
缺点：注册**需要信用卡验证**（不扣费），开机要挑区域。

```bash
# 在 VM 上
sudo apt update && sudo apt install -y nodejs npm ffmpeg git
git clone <你的仓库> && cd app
npm install --omit=dev
cp .env.example .env && nano .env    # 填配置
npm start                              # 或 pm2 start server.js --name pipeline
```

### 方案 C：仓库托管 —— GitHub

- 代码放 GitHub（免费无限私有仓库）
- ⚠️ **不要**把 `assets/bgm/` 里 47MB 的 mp3 直接提交，用对象存储或 Git LFS
- ⚠️ **绝对不要**提交 `.env`

## 三、数据库接入（存视频与提示词）

### 已实现的存储层

项目新增了 [src/storage/](../app/src/storage/)，业务代码只调统一接口，底层可切换：

```
src/storage/
├── index.js              # 统一入口（自动选驱动）
├── schema.sql            # PostgreSQL 建表脚本
└── drivers/
    ├── jsonfile.js       # 本地 JSON（默认，零依赖）
    ├── postgres.js       # PostgreSQL（Supabase / Neon / 自建）
    └── sqlite.js         # SQLite（可选）
```

**默认行为不变**：不配 `DATABASE_TYPE` 时仍用本地 JSON 文件，现有数据完全兼容。

### 数据表设计

| 表 | 存什么 |
|---|---|
| `tasks` | 一次生成作业：提示词、参数、状态、产物路径 |
| `clips` | 每段视频：片段提示词、状态、质检结果、本地路径 |
| `prompts` | **提示词库**：沉淀可复用的提示词，带主题标签与使用次数 |
| `video_assets` | **视频资产元数据**：文件本体在对象存储，库里只存 URL/大小/时长 |
| `templates` | 主题模板库 |
| `app_settings` | 全局配置（提示词优化规则等） |

> 💡 **重要设计**：视频文件本体**不要**塞进数据库（免费额度会被撑爆，读写也慢）。
> 正确做法是：视频传对象存储，数据库只存元数据和 URL —— 这就是 `video_assets` 表的作用。

### 接入 Supabase（推荐，免费额度最大方）

1. 注册 https://supabase.com → 新建项目
2. 打开 **SQL Editor**，把 [schema.sql](../app/src/storage/schema.sql) 全文粘贴执行
3. 打开 **Project Settings → Database**，复制 **Connection string (URI)**
4. 在 `.env` 里配置：
   ```ini
   DATABASE_TYPE=postgres
   DATABASE_URL=postgresql://postgres:你的密码@db.xxxx.supabase.co:5432/postgres
   ```
5. 安装依赖并迁移历史数据：
   ```bash
   npm install pg
   npm run db:migrate      # 把已有 data/tasks/*.json 灌进数据库
   ```
6. 重启服务，看到 `[storage] 驱动: postgres` 即成功

### 视频文件存哪：Supabase Storage

数据库存元数据，文件本体存 Storage（免费 1GB）：

```ini
STORAGE_DRIVER=supabase
SUPABASE_URL=https://xxxx.supabase.co
SUPABASE_SERVICE_KEY=你的 service_role key
SUPABASE_BUCKET=videos
```

> 在 Supabase 的 **Storage** 里先建一个名为 `videos` 的 bucket。

其他可选：Cloudflare R2（10GB 免费，无出网流量费）、阿里云 OSS。

## 四、云上必须注意的坑（已在代码里修好）

| 原本的问题 | 已做的修复 |
|---|---|
| ffmpeg 路径写死本机 | [config.js](../app/config.js) 改为读 `FFMPEG_PATH` 环境变量，留空则用系统 PATH |
| 端口写死 3000 | 改为读 `PORT` 环境变量（云平台自动注入） |
| 只监听 localhost | [server.js](../app/server.js) 改为监听 `0.0.0.0`，容器外可访问 |
| API Key 明文写在代码里 | 全部改为环境变量，`.env` 进 `.gitignore` |
| 无访问控制 | 新增 `ACCESS_TOKEN` 配置项，公网部署务必设置 |

## 五、环境变量速查表

完整模板见 [.env.example](../app/.env.example)。

| 变量 | 必填 | 说明 |
|---|---|---|
| `PORT` | 云平台自动注入 | 监听端口 |
| `ACCESS_TOKEN` | **公网强烈建议** | 访问口令，防止盗刷 AI 额度 |
| `DATABASE_TYPE` | 推荐 | `postgres` 启用数据库 |
| `DATABASE_URL` | 推荐 | 数据库连接串 |
| `STORAGE_DRIVER` | 可选 | `supabase` 时视频走对象存储 |
| `OPENAI_API_KEY` | 可选 | 提示词优化用的 LLM |
| `SILICONFLOW_API_KEY` 等 | 可选 | 各视频生成模型 |
| `FFMPEG_PATH` | 可选 | 留空用系统 ffmpeg（Linux 推荐） |

> 不填任何 AI Key 也能跑：系统走 Mock 模式，可完整演示流程。

## 六、成本提醒

| 项目 | 免费额度 | 超了怎么办 |
|---|---|---|
| Hugging Face Space | 2vCPU/16G，会休眠 | 升级付费硬件 |
| Supabase 数据库 | 500MB | 升级或清理旧任务 |
| Supabase Storage | 1GB | 用 Cloudflare R2（10GB 免费） |
| **AI 视频生成 API** | ⚠️ **通常按量付费** | **这是最大开销，务必设 ACCESS_TOKEN 并监控用量** |

**最后一句忠告**：AI 视频生成 API 是唯一真正烧钱的地方。服务一旦公开，别人点几下就能花掉你的余额。
上线前**一定**设 `ACCESS_TOKEN`，并给 API 账户设置消费上限。
