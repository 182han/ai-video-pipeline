## 一、先说结论

1. **合并：没有这个功能。** DSH 不能把两个会话合并成一个。每个会话是一份独立日志（`.zstd`），互不可见。
2. **关闭/清理：用「归档」。** 界面里**没有「删除会话」入口**，只有归档；归档可随时恢复。
3. **为什么你找不到入口**：那个按钮**只在鼠标悬停到会话行上时才出现**（原本显示时间的位置会变成 `⋯`）。不悬停就永远是空的，所以看着像没有入口。

## 二、入口与操作（左侧栏）

1. 左侧栏 → 展开工作区「测试」
2. **鼠标移到某个会话行上，不要点** —— 行尾的相对时间会变成一个 `⋯` 按钮
3. 点 `⋯` 打开菜单：**重命名 / 分叉会话 / 置顶会话 / 归档会话**
4. 悬停时行尾还会直接出现一个「归档」图标按钮（带提示，悬停 0.5 秒出现）
5. 归档后怎么找回：侧栏顶部「筛选会话」→ 选
   - **全部对话（显示已归档）**：显示全部，含已归档
   - **隐藏已归档**：只看在用的
   - **仅显示已归档**：只看归档的
   → 已归档的行带「已归档」标记，菜单里对应变成「取消归档」

补充事实：

- **分叉会话**（菜单项 / 默认快捷键 `Ctrl+Alt+F`）：从当前会话某个**已结束的轮次**拉一个分支，形成「祖先会话 / 后代会话」层级，用于「保留原上下文再试另一条路」。这是最接近「分支」的能力，但它**不会合并**回原会话。
- 其他默认快捷键：重命名 `Ctrl+Alt+G`、归档 `Ctrl+Shift+A`。快捷键随版本可能变，以菜单显示为准。
- **归档会先停止该会话里正在运行的工作**，并弹确认框（「停止并归档」）。所以别对正在跑 AgentTeams 的会话随手归档。
- 工作区层面的「删除工作区」只是从列表移除，**文件夹和会话都保留**，那些会话会掉到「未分组」下。

## 五、以后怎么少开窗口

这次的根因不是窗口多，是**同一个项目的上下文被切成了十几份**。三条规矩：

1. **一个项目一个主战场会话** —— 新需求继续在这个会话里说，不要新开
2. **要开新窗口前，先让主战场写一句结论**（决定了什么、否掉了什么），落进 `PROJECT_STATE.md`
3. **子任务用 subagent / AgentTeams，不要手动开新会话** —— 手动开出来的会变成独立窗口，`/agent-teams` 或让 Agent 派子代理则不会
