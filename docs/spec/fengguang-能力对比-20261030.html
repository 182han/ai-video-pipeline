2. 同一需求，前后各写一条

左=旧规则（app 里 v0.1 的 rules 原文），右=当前 v0.2.6。两边都是完整可投喂提示词。

旧版 · c1 冰岛极光

绿色极光帘幕自天顶垂落，边缘泛淡紫，长曝拖尾拉出垂直光带。前景海岸玄武岩与苔原剪影压住下缘，远处小镇灯火极小、偏右下角作尺度参照。固定机位，24mm 广角，地平线压在下三分之一。光源为天顶极光本体，冷绿主调，暖色只剩地平线一线。海上薄雾浮动，空气潮湿。亮度压至 80，暗部约 27%，高光受控、天空不过曝，轻微颗粒。画面停在帘幕与海岸线交接处，无新元素进入。

新版 · c1 冰岛极光

冰岛黑沙滩海岸，一整片氧绿极光帘幕从头顶垂到海平线，竖直光柱缓慢起伏，远处小镇只余几点暖黄灯火。碎浪在黑沙上反复推铺。海岸低机位 14mm 极慢前推，前景压一角玄武岩。无月夜，绿光自上落下，湿沙与海面映出微弱青绿，洋红只留在帘幕边缘。安静辽阔。暗底冷调，绿与青灰分离，暖点只有那几点灯，高光受控、天空不过曝。画面停在帘幕与灯火之间，无新元素进入。
差在哪：
  • 颜色规则：旧版“边缘泛淡紫”——正是 skill 失败表里的“紫雾/紫边”风险；新版“氧绿为主、洋红只留在边缘”。
  • 参数 vs 画面：旧版把“亮度 80、暗部 27%”写进提示词，模型不认这些数；新版换成“暗底冷调、绿与青灰分离”。
  • 机位焦段：旧版 24mm 固定机位，新版低机位 14mm 极慢前推——按机位族选焦段，且只一条运动轴。

    新版 · c2 丹霞

    丹霞峰丛从低雾里一层层露出来，赤壁的层理被雾切成上下两截，云顶被照亮、山体仍暗。低雾沿谷地缓慢漫过峰腰。航拍中位 35mm 极慢推进，机头不带俯冲。日出后十分钟的侧逆光从右后方斜切，雾顶镶暖边，峰体留在冷暗里。清冷而克制。暖浓偏收敛，赭红只在受光边缘，暗部保留层理，高光受控、云顶不过曝。画面停在雾与峰脊交界，无新元素进入。

  • 旧版同样把“亮度 105、饱和 0.30”写进画面描述；新版只留“暖浓偏收敛”。
  • 新版补了“航拍中位 35mm，机头不带俯冲”——把“别双轴”写死在句子里，旧版只靠“极慢推进”约束。

    沙丘迎风坡的风纹自画面前景斜向深处，一道脊线切成明暗两半。只有风在动，沙粒顺脊背薄薄滑落。固定机位，85mm 长焦压缩，地平线落在上三分之一。日落后的低角度暖光从左侧掠来，阳面泛金、背风滑落面沉成冷紫。空气干燥，热浪轻微。亮度 110，饱和 0.28，高光受控、天空不过曝，细颗粒、低对比。负空间 60%，无尺度点景。画面停在沙脊消失于暗部处，没有新元素进入。

    新版 · c3 沙漠孤独感

    一道沙丘脊线斜切过画面，迎风坡刻满细密风纹，背风面滑落成一片干净的暗面，四周没有任何足迹与草木。细沙被风从脊线扬起，贴着坡面缓慢横移。400mm 长焦静态机位，压缩脊线的弧度。日落前极低侧光，亮面暖金、暗面沉进冷蓝，明暗交界锋利如刃。孤独到近乎空。近似单色的暖调，只留一个主色，细腻颗粒，高光受控、天空不过曝。画面停在空荡的脊线上，除了沙什么都不动，没有新元素进入。
    差在哪：
  • 旧版“阳面泛金、背风面沉成冷紫”——紫调阴影是极光/月光题材之外的另一个惯性；新版“暗面沉进冷蓝”。
  • 新版把“孤独”落到可拍的东西：没有足迹、没有草木、只有沙；旧版靠“负空间 60%”这种参数表达。

    帘状跌水从玄武岩崖壁整幅垂落，水线细密，砸入潭面激起白雾。水雾从潭面浮起漫过岩壁，苔藓与湿石压住前景一角。极慢推进，35mm，地平线在画面下三分之一。阴天散射光自上方均布，冷青主调，岩壁暗部偏蓝绿。空气潮湿冰凉，可见细小水珠。亮度 105，饱和 0.26，高光受控、水花不死白，低对比、细颗粒。画面停在水雾漫过瀑口处，没有新元素进入。

    新版 · c4 瀑布清凉

    峡谷深处的多级跌水瀑布，水帘从苔藓覆盖的岩阶上一层层砸下，湿岩发黑，水雾贴着潭面浮起。水雾缓慢上升、被风带偏。贴壁 24mm 极慢横移，前景压一角湿苔石。阴天散射，天光从谷口上方落下，岩壁与水面都无硬影。清凉、湿润、安静。极冷极淡，青灰与苔绿为主，水沫高光受控、不炸成纯白。画面停在瀑布与潭面的雾里，无新元素进入。
    差在哪：
  • 旧版“阴天散射光自上方均布”——没有方向，等于没写光位；新版“天光从谷口上方落下”（§八 新规则：阴天必须补光从哪来）。
  • 旧版“极慢推进 35mm”是地面平视；新版“贴壁 24mm 极慢横移”，机位族与焦段匹配，且只一条轴。
