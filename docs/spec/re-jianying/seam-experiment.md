# 接缝自然度对照实验：转场曲线 vs 校色匹配

> 日期：2026-10-27 ｜ 脚本：`proto/seam-abcd.mjs`（`--a/--b/--tag` 可换片段）
> 度量：直接复用 `app/src/qualityChecker.checkSeam`（与线上质检同口径）
> 产物：`app/output/verify_seam_abcd/{pair1,pair2,pair3}/`（A/B/C/D/D2 五个 mp4，可直接看）

## 实验设计

每组取两段真实片段各 3 秒（1280×720 / 30fps / yuv420p），接缝固定在第 3 秒；转场时长 0.4s。

| 组 | 处理 | 目的 |
|---|---|---|
| A | 硬切 | 基线 |
| B | 线性叠化（`xfade=fade`） | 现状 |
| C | 缓入缓出叠化（smoothstep 权重） | 验证「换曲线」 |
| D | `eq`+`colorbalance` 粗校色 + 线性叠化 | 验证「校色」 |
| D2 | 逐通道均值/方差匹配（Reinhard 式 `lutrgb`）+ 线性叠化 | 验证「正经校色」 |

指标分两层：
- **镜头级失配**：两段画面均值的 ΔY / ΔE76 —— 这是转场开始前眼睛就已经看到的差。
- **接缝指标**：`checkSeam` 的跨缝 SSIM / ΔE76 / ΔY / MAD× —— 这是转场瞬间的呈现。

## 结果

|---|---|---|---|
| pair1 | **42.98** | 36.26 | **1.60** |
| pair2 | **48.24**（ΔY +91.3） | 13.59（ΔY +4.66） | **1.41**（ΔY +2.32） |
| pair3 | **25.49** | 23.31 | **3.64** |

## 结论

1. **换转场曲线基本没用。** C 相对 B：pair1 好 1.07、pair2 好 1.97、**pair3 反而差 0.54**。
   曲线只在「有差异可遮」时帮一点，且不稳定 → **不值得为它去逆剪映的转场资源**。

2. **校色匹配收益大且稳定。** 镜头级 ΔE76 从 43/48/25 降到 **1.6/1.4/3.6**；
   接缝 ΔE76 从 8.07/9.82/0.29 降到 **0.34/0.69/0.28**。pair2 连 SSIM 都从 0.88 提到 0.93。

3. **粗校色（eq+colorbalance）不够。** pair2 亮度差高达 +91.3，`eq` 只压到 +4.66；
   逐通道均值/方差匹配能压到 +2.32。要做就做后者，别用 `eq` 糊。

4. **发现一个质检盲区（重要）。** pair3 的 B 组接缝指标是 **ΔE76 0.29 / ΔY −0.13 / SSIM 0.78**，
   按现有阈值「通过」，但两段镜头级 ΔE76 高达 **25.49** —— 转场瞬间看着顺，前后镜头色调却是不连贯的。
   也就是说：**`checkSeam` 只看接缝中心帧，测不到「镜头整体色调跳变」**。

## 建议

### 1）拼接前做「镜头级色彩连续性」校验（成本最低，先做这个）

在 `checkSeam` 之外增加一项（或在 `checkConcat` 里加）：

```
对相邻片段各取若干帧 → 算 Y/U/V 均值 → ΔE76(片段均值)
  ΔE76 ≤ 15  ：通过
  ΔE76 > 15  ：记录「色调不连续」，不直接判 fail（风景片里冷暖对比可能是刻意的）
```

阈值 15 是本次数据给的起点（合格组 1.4–3.6，不合格组 25–48），**需在更多真实成片上标定**。

### 2）校色放在拼接前，按「参考镜头」匹配而不是「逐段链式匹配」

- 链式匹配（每段对齐上一段）会**累积漂移**，30 分钟成片可能整体偏色。
- 建议：每段对齐**同一参考段**（首段或全片中位段），或限制单段最大增益（如 ≤ ±15%）。
- 实现：`lutrgb` 逐通道 `val*g+o`，参数由采样帧的均值/方差算出（本脚本 `rgbStats()` 可直接复用）。

### 3）转场曲线：保持现状（线性 `xfade=fade`），不要为此逆向剪映

同时说明：剪映的转场是**平台资源包**驱动，本机 `Cache/effect`（10842 文件）里没有任何含
`transition` 的包，`videoeditor.dll` 也没有内建转场 shader 符号（`render_transition`/`transition_shader` 命中 0）。
要拿到真曲线，得先在剪映里联网下载并应用一次转场 —— 按本次实验结论，**投入产出不划算**。

## 局限（别把结论说过头）

- 只有 **3 对片段、各 1 道缝**，且都来自户外/自然题材；结论方向可靠，具体数值需扩样。
- 接缝指标在 B/C/D/D2 上测的是**混合帧**，所以它主要反映「转场瞬间」，不能单独用来判「整片色调连贯」——
  这也正是建议 1 要补镜头级指标的原因。
- `D2` 的匹配参数由同一段素材自身统计得出（离线），**没有模拟真实流水线里「先测后调」的误差**。
