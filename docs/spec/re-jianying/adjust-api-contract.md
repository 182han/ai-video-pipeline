## 1. 参数总表

所有数值滑杆范围 **−50 ~ +50**，默认 0（0 表示不调节，不发这个字段也行）。

| 字段 | 含义 | 范围 | 已验证 |
|---|---|---|---|
| `temperature` | 色温 | ±50 | ✅ 41.71 dB |
| `tone` | 色调 | ±50 | ✅ 41.10 dB |
| `saturation` | 饱和度 | ±50 | ✅ 40.36 dB |
| `brightness` | 亮度 | ±50 | ✅ 41.13 dB |
| `contrast` | 对比度 | ±50 | ✅ 38.09 dB |
| `highlight` | 高光 | ±50 | ⚠️ 公式来自引擎，无图像对照 |
| `shadow` | 阴影 | ±50 | ✅ 42.22 dB |
| `white` | 白色 | ±50 | ⚠️ 同上 |
| `black` | 黑色 | ±50 | ⚠️ 同上 |
| `lightSensation` | 光感 | ±50 | ✅ 40.95 dB |

## 2. 复合参数

### 2.1 HSL（8 色相带 × 3 参数）

```json
"hsl": [
  [0, 0, 0],   // 红
  [0, 0, 0],   // 橙
  [0, 0, 0],   // 黄
  [0, 0, 0],   // 绿
  [0, 0, 0],   // 青
  [0, 0, 0],   // 蓝
  [0, 0, 0],   // 紫
  [0, 0, 0]    // 品红
]
```

每项 `[色相, 饱和度, 亮度]`，范围 **−100 ~ +100**（与基础滑杆不同，注意）。
数组必须是 8 项；缺省项按 0 处理；非数组会被整体丢弃。

### 2.2 曲线

```json
"curve": [
  [[0,0],[0.5,0.55],[1,1]],   // R
  [[0,0],[0.5,0.5],[1,1]],    // G
  [[0,0],[0.5,0.5],[1,1]]     // B
]
```

每通道若干控制点 `[x, y]`，x/y ∈ 0..1，按 x 升序（乱序会被排序）。少于 2 点的通道视为恒等。

### 2.3 色轮（一级色轮）

```json
"wheel": {
  "lift":  { "r": 0, "g": 0, "b": 0, "y": 0 },
  "gamma": { "r": 0, "g": 0, "b": 0, "y": 0 },
  "gain":  { "r": 0, "g": 0, "b": 0, "y": 0 }
}
```

- 每个通道值范围 **−1 ~ +1**（0 表示不变）
- 对应面板：暗部 = lift，中灰 = gamma，亮部 = gain，偏移 = offset
- 内部使用引擎公式：`gamma<0 → 1-4g`，`gamma>0 → 1/(1+4g)`

## 3. 提交方式（⏳ 待接线）

```http
POST /api/tasks
Content-Type: application/json

{
  "prompt": "...",
  "preset": "final",
  "adjust": { "brightness": 10, "saturation": 15 }
}
```

后端行为（接线后）：

1. `taskManager` 只保留白名单字段，数值钳到合法范围；非法值（字符串、NaN、Infinity）**丢弃**
2. `pipeline` 在最终转码前把参数烘焙成 3D LUT + 空间滤镜
3. `GET /api/tasks/:id` 会回显 **规范化后的** `adjust`（钳制后的值），前端以此为准
4. 全部为 0 / 非法 → 等价于不调节，导出结果与现在逐帧一致

## 4. 前端 UI 建议

### 4.1 面板结构（对应剪映「调整」）

```
基础 | HSL | 曲线 | 色轮 | 蒙版
```

- **基础**：4 组
  - 色彩：色温 / 色调 / 饱和度 / 自然饱和度（无实现，建议隐藏）
  - 明度：亮度 / 对比度 / 高光 / 阴影 / 白色 / 黑色 / 光感
  - 效果：锐化 / 清晰 / 颗粒 / 褪色 / 暗角
- **HSL**：8 色轮 + 每轮 色相/饱和度/亮度 三滑杆
- **曲线**：RGB 曲线（L/R/G/B）
- **色轮**：暗部 / 中灰 / 亮部 / 偏移 四轮 + 强度
- **蒙版**：暂不支持，建议隐藏或置灰

### 4.2 预览

面板里的实时预览**不要**走后端 ffmpeg（会卡）。建议：

```css
/* 粗略示意，非精确 */
filter: brightness(...) contrast(...) saturate(...) sepia(...);
```

精确预览需要低分辨率代理 + 逐帧 LUT，属第二阶段；先保证**导出正确**。

### 4.3 状态提示

| 状态 | 建议文案 |
|---|---|
| 未调节 | 无提示 |
| 已调节（导出时生效） | 「导出时应用」 |
| 参数非法被丢弃 | 不提示（静默按合法值处理） |
| 资源缺失（如 LUT） | 「部分效果不可用」，且**不能显示为已应用** |

## 6. 已知限制（UI 需要知道）

1. **自然饱和度**未实现（剪映是 AI 项，无本地资源）
2. **智能调色 / 色彩克隆 / 色彩校正**未实现（AI 云端能力）
3. **蒙版**未实现（需要区域跟踪）
4. 锐化/清晰/颗粒/暗角是 ffmpeg 近似，**不是逐像素复刻**
5. 光感/褪色依赖内置 LUT 资源（`app/assets/adjust/`），**分发前需评估剪映资源授权**
