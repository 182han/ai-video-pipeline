# 视频生成模型对比：只靠官方介绍 + 你已有的生成结果

> 前提：**不再花钱、不新生成任何视频**。本报告所有对比只用两类材料：
> ① 各家官方文档 / 官网介绍里白纸黑字写的能力；② 你项目里历史跑出来的真实片段（`app/clips/`）。
> 撰写：2026-10-25。价格与参数为当日公开口径，可能变动。

---

## 先回答你的问题：能不能不花钱就直接比？

**能比“能力”，不能比“画风”。** 这条边界必须先说清楚，否则报告就是在骗自己：

| 能不能比 | 说明 |
|---|---|
| ✅ **能不能做**（分辨率、时长、参数、成本、接不接得上） | 官方文档写得很清楚，可以逐条对比 |
| ✅ **你项目里的真实结果好不好**（清晰度、曝光、黑帧、镜头是否乱切） | 历史片段还在硬盘上，可以实测 |
| ❌ **哪家画风质感最好** | 这需要同一个提示词的真实产出。官方发布会样片都是精选的，不能当证据 |
| ❌ **可灵 / Seedance 在你这个题材上到底几斤几两** | 你项目里没有它们的任何真实片段，只能写“未验证” |

所以下面的结论分两层：**能力层（官方口径，可靠）** 与 **画风层（项目实测，只覆盖万相）**。

## 一、能力对比（官方口径）

| 项目 | Wan 3.0（阿里百炼） | Kling VIDEO 3.0 | Seedance 2.5（火山方舟） | Veo 3.1（Google Gemini API） |
|---|---|---|---|---|
| 分辨率 | 480P / 720P / 1080P | 实测项目代码按 720P / 1080P / 4K 三档映射 | 480P / 720P / 1080P（你项目适配层只暴露前两档） | 720p / 1080p（部分资料另提 4k） |
| 单段时长 | 2–30 秒（传 -1 为智能时长） | 3–15 秒（Flexible Duration） | 4–30 秒，支持多轮延长 | 官方文档写 4 / 6 / 8 秒 |
| 帧率 | 30fps | — | — | — |
| 原生音频 | 有，`audio` 可关 | 有（原生音画同源），分档计费 | 声画质感升级 | 原生音频 |
| 负面提示词 | 未作为独立字段 | 支持（≤2500 字） | 需查当期文档 | 支持 `negative_prompt` |
| 首帧/首尾帧 | 支持 | 支持（Start & End Frames） | 支持 | 支持（图生视频） |
| 多镜头/多镜 | 无 | **Multi-Shot / Custom Multi-Shot**（AI 导演，自动分镜） | 参考素材上限提升至 50 个 | 3.1 支持参考图扩展 |
| 参考素材能力 | 四模态（文本/图/音/视频），最高 20 个素材 | 支持元素/视频参考，多角色一致性 | 50 个多模态参考 | 参考图生视频 |
| 计费 | 按秒；官网口径 480P ¥0.45 / 720P ¥0.9 / 1080P ¥1.8 每秒；失败不计费 | 按积分/秒，无声档更便宜 | 按套餐/秒 | 按秒（Veo 3.1 Fast / Lite 更低） |
| 在你项目里的真实片段 | **9 段**（2 个批次） | **0 段** | **0 段** | **0 段** |
| 接进现有代码 | 已有适配器，真跑过 | 已有适配器，**接口字段是旧版**（见第三节） | 已有适配器，分辨率档位未开放 | **未接入** |

**读表要点：**

1. **万相的独特优势不在“参数最花哨”，而在“和你的长片模式对得上”**：30 秒上限 + 可关音频 + 可关提示词改写 + 失败不计费。它的“四模态参考、最高 20 素材”是给角色/产品片准备的，你基本用不上。
2. **可灵 3.0 的长处在“叙事与分镜”**：Multi-Shot 会自动调机位、出多镜头。这对你要的“极缓慢单镜头风光”反而是**干扰**，使用时需要明确关掉。
3. **Seedance 2.5 的长处是“长叙事 + 贴时间戳编辑”**，同样偏叙事，但它的 30 秒直出能力最接近万相。
4. **Veo 3.1 是“8 秒 + 原生音频”的短篇高手**，写实质感口碑好，但单段短、你也没接，属于“值得观察，暂不进流水线”。

## 三、用官方介绍就能提前发现的“坑”（对你项目尤其重要）

### 坑 1：可灵 3.0 的 Multi-Shot 会把你的单镜头拆成多镜头

官方用户指南写得很明确：开启 Multi-Shot 后，"模型会自动规划镜头切换"。你的需求是**一条主轴、极缓慢运动、零切换**。稳妥做法是：**默认关闭 Multi-Shot**，只在“集锦段”偶尔用一次。

### 坑 2：你项目里的可灵适配器参数可能已过期

`app/src/generators/kling.js` 里写死了 `kling-v3` 与 `mode: std/pro/4k`，这是 2.x 时代的参数结构。可灵 3.0 的官方能力表里**没有列出 4K**（只列了 720p / 1080p 两档价格）；而 Multi-Shot、flexible duration 等新能力也不是这套参数能表达的。**换模型之前先按官方最新 API 文档核对一遍字段**，否则可能“生成成功但效果不是你想要的”。

### 坑 3：Veo 3.1 单段只有 4–8 秒

官方文档写的是 "Veo 3.1 is a model for generating 8-second videos"。你现在每段 6–7 秒恰好能对上，但**它无法做 30 秒长镜头**。如果你未来想做“一镜到底”的云端延时，它天然出局。

### 坑 4：Seedance 2.5 的“30 秒直出”在你项目里用不上

你项目适配层里 Seedance 的分辨率只暴露 `480p / 720p`，模型长什么、怎么调，**都还没接**。它的官方能力（50 个参考素材、时间戳编辑）是给叙事片准备的。

### 坑 5：Wan 3.0 的“智能改写”默认是开的

官方文档写明 `prompt_extend` 默认 `true`。你项目已经显式关掉了——这对你很重要，因为**你的提示词已经经过自己的优化器**，再被模型改写一遍就改乱了。换任何新模型，第一件事都应该是确认“能不能关自动改写”。

## 四、结论（只靠官方介绍能下的判断）

1. **在“能不能接进你的长片流水线”上，Wan 3.0 仍然是唯一被证明可用的**：有真实片段、30 秒、可关声、可关改写、失败不计费。
2. **在“官方介绍看起来最先进”上，可灵 3.0 和 Seedance 2.5 都不弱**：一个主打 AI 导演与原生音画，一个主打 30 秒直出与 50 素材。但它们的先进点**大多指向叙事片，而不是你要的静默风光长片**。
3. **在“画风质感”上，官方介绍给不出答案**，必须实测。这也是为什么上一轮我给了 5 组提示词入口——如果哪天愿意花几十块钱，只需要跑其中 1 组就能立刻验证。

**一句话：不花钱时，你的证据只能支撑“继续用万相”，不能支撑“万相最好”。把这句话写进汇报，比写“万相最好”更安全。**

## 附录：测量命令（可复现）

```powershell
$FF = "C:\Users\14872\Desktop\测试\app\tools\ffmpeg\bin\ffmpeg.exe"
$FP = "C:\Users\14872\Desktop\测试\app\tools\ffmpeg\bin\ffprobe.exe"
$VID = "C:\Users\14872\Desktop\测试\app\clips\task_mv4v7qp2_m8r0_clip_1.mp4"

# 时长 / 分辨率 / 帧率 / 码率
& $FP -v error -show_entries format=duration,bit_rate,size:stream=width,height,r_frame_rate,nb_frames -of json $VID

# 清晰度（blurdetect 逐帧）
& $FF -hide_banner -nostats -i $VID -vf "blurdetect,metadata=mode=print:key=lavfi.blur:file=-" -an -f null NUL 2>$null

# 平均亮度 / 过曝 / 欠曝
& $FF -hide_banner -nostats -i $VID -vf "signalstats,metadata=mode=print:key=lavfi.signalstats.YAVG:file=-" -an -f null NUL 2>$null

# 黑帧
& $FF -hide_banner -nostats -i $VID -vf "blackdetect=d=0.3:pix_th=0.10" -an -f null - 2>&1 | Select-String "black_start"

# 镜头内是否有硬切
& $FF -hide_banner -nostats -i $VID -vf "select='gt(scene,0.3)',metadata=mode=print:key=lavfi.scene_score:file=-" -an -f null NUL 2>$null
```
