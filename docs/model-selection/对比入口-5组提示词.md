# 大模型对比 · 5 组提示词入口（同题同分辨率）

> 用途：你把这 5 组提示词分别喂给其他视频生成平台，生成后把视频发我，我来做逐项对比。
> 左侧"已有画面"全部来自**你项目里万相 3.0 的真实生成**（`app/clips/`），可作为每个方向的参照基准。

## 使用前先定三件事（否则对比不公平）

| 项 | 固定值 | 为什么 |
|---|---|---|
| 分辨率 | **720P / 1280×720** | 与现有费样本一致；项目交付屏保也是这个档位 |
| 画幅 | 16:9 | 项目交付形态 |
| 时长 | 6 秒左右 | 现有样本 6–7 秒；太短看不出镜头运动 |
| 自动改写 | **关闭**（prompt rewrite / prompt_extend） | 这些提示词已包含运镜光影质感，被改写就变成"两个提示词"了 |
| 自带声音 | **关闭** | 项目有独立配乐 |
| 负面提示词 | 平台支持就填 | 见文末通用负面词 |

建议做法：**每个模型每个方向生成 2 次**（避免一次抽中"运气帧"），一共 5 组 × N 家 × 2 次。

## 我会怎么判（让你提前知道评分口径）

每个方向按 100 分评，五项各 20 分：

| 维度 | 怎么看 | 权重逻辑 |
|---|---|---|
| 主体清晰与细节 | 是否有一个明确主角；细节是否塌成色块 | 屏保长片最怕"什么都好看但什么都不突出" |
| 光影与曝光 | 光源是否有方向；天空是否死白；暗部是否发灰 | 实测专业风光片高光占比只有 0.2%–3.4% |
| 运动可信度 | 慢推/雾动是否匀速、是否抽搐、是否突变镜头 | 长片连续播放时，抖一下就毁了 |
| 画风一致性 | 同一模型 5 个方向之间风格是否自洽 | 项目要拼成一条片子，不能一段一个画风 |
| 项目适配度 | 分辨率、时长、能否关声、能否关改写、单段成本 | 决定能不能进现有流水线 |

最后会落到一张表：**每个模型 × 每个方向**，并给出"最推荐 × 用于哪些镜型"的具体结论。

## 说清楚一件事：同题对比的天平本来就不平

- **提示词长度**：我这 5 组都是"全量版"（主体 + 运镜 + 光影 + 质感 + 否词），对**短提示词更敏感**的模型（例如某些只吃 200 字的平台）会吃亏；对"越详细越好"的模型更有利。所以结果我会分两类看：**长提示词上限**与**短提示词下限**。
- **中英差异**：A/B/C 是英文、D/E 是中文。部分模型对中文更敏感，部分对英文更敏感；我会在结论里注明，必要时补一组同题中英对照。
- **次数**：一次生成不构成结论，所以建议每个方向 2 次。
