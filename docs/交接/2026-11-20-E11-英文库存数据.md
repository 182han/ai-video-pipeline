# E11 · 英文界面库存数据零中文（2026-11-20）

> 用户反馈：英文界面下，库存里的历史记录仍有中文名称；片段库、图片库仍显示中文版提示词。
> 本文记录**根因、改动、验收证据、未验证项**。结论三态：离线通过 / live 未验证（需重启 3001）。

## 0. 一句话结论

- **历史任务名**：新增 `src/taskEn.js` + `assets/library/tasks-en.json`，`/api/tasks`、`/api/tasks/:id`、
  `/api/tasks/completed`、任务回收站都输出 `promptEn`；英文界面用它，解析不到显示英文占位，**不再回退中文**。
- **图片库提示词**：新增 `src/photoEn.js` + `assets/library/photos-en.json`，`/api/photos`、`/api/photos/:id`、
  回收站输出 `promptEn`；9/9 条历史中文图都能离线得到英文（场景卡模板 3 条 + 人工词表 6 条）。
- **片段库**：E10 已做，本次再加一层**接口兜底**（`/api/library` 对没有持久化 `promptEn` 的条目即时解析），
  并让英文搜索命中 `promptEn`。
- **其他同源显示点**：统一任务名（`taskName.js`）、任务详情抽屉、顶栏任务条、剪辑台素材卡、配乐/调色任务列表
  也改为英文优先；不再是「库页英文、别的页中文」。

## 1. 根因（不是猜，按代码与接口实测）

1. E10（`a8f718c`）只覆盖了 **Library 的 clip / final 条目**（`src/libraryEn.js`，入库与回填写入 `promptEn`）。
   - 任务对象（`/api/tasks`）没有 `promptEn`，而库存「未完成 / 任务回收站」直接渲染 `t.prompt` → 中文。
   - 图片库条目（`/api/photos`）没有 `promptEn`，前端直接渲染 `p.imagePrompt || p.prompt` → 中文。
2. 图片库现有数据实测：24 条中 **9 条中文**（3 条来自场景卡任务、6 条历史图只有中文）；
   任务库实测 43 条中 **31 条中文提示词**。
3. `/api/library` 的片段条目本身 23/23 都有 `promptEn` 且零 CJK（live API 实测），
   因此若用户仍在片段 tab 看到中文，属于旧页面/旧进程或条目缺字段；本次加了接口兜底与英文搜索。

## 5. 已知边界

- 无法离线解析的历史中文任务（尤其是 mock 测试任务）会显示 `(Chinese original · no English version)` 占位。
  这是 E10 定下的口径：**不冒充翻译、不偷偷调模型**（AGENTS §4.9）。
- 词表是人工撰写的；新增历史中文任务/图片若需要英文，按 `byTaskId` / `byId` 追加即可，然后重跑
  `node scripts/verify-en-data.js`。
- 图片库可编辑文本框仍是原始中文数据（见 §2 末尾）。
