## 1. 目标页面（登录后的 `/`）

**整页 = 小智对话页**，不是六步向导；六步向导保留在 `/create`，左栏「创作」进入（后台/高级入口，功能不变）。

布局（从左到右、从上到下）：

1. **左栏**：竖排导航气泡，4 项：创作 / 剪辑 / 库 / 设置（标签可沿用现有“库”；用户草图写“库存”，如改文案同步导航测试）。
   - 顶部或侧边有**三个点**按钮：点击收起为图标条（约 56–64px），再点展开（212px）；收起/展开要有过渡；状态可 localStorage 记住。
   - 各项竖直对齐、可点击进入对应界面；当前项高亮（P2/P3 金色 accent）。
2. **主区顶部**：一个**大号小智球**（绿色发光球，沿用现有 orb 视觉，约 96–140px），旁边/下方有页面标识。
3. **介绍卡（关键）**：在**大球与对话窗口之间**，一张横向卡片，1–2 句像 agent 开场白，例如：
   - “我是小智，告诉我视频多长、想拍什么，我来排计划并自动完成。”
   - 可带 3 个建议 chips（如“30 分钟的雪山、星空和极光”“上一次的视频”“现在进度怎样”）。
   - 有对话后介绍卡可收起/缩小（或保留在顶部），消息区在下方滚动。
4. **对话区**：复用现有 `assistant.js` 的消息/计划卡/状态机/记忆/ASR 逻辑；用户消息与助手消息气泡；计划卡、确认执行、进度状态条照旧。
5. **底部输入框（关键）**：**固定在页面下方**（主区底部，像微信），不是右下角浮动面板；包含文本框（自适应高度）、语音（按住说话/ASR）、发送按钮；空态时也可直接输入。
6. **背景/景色**：整页深绿/祖母绿渐变或极光光晕，与大球绿色同源、相互呼应；保持 P2/P3 暗色+金色可读性；不要引入新图片依赖，优先 CSS 渐变/径向光。

空态：大球 + 介绍卡 + 建议 chips + 底部输入框。
有消息：大球缩小/上移，介绍卡收起，消息区滚动，输入框固定底部。
