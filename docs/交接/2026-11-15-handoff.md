## 7. 已定产品决策（不要重新讨论）

**信息架构**
- 库存改为一个「库」：三个 tab **成片 / 片段 / 图片**；长视频就是“成片”，不再单独入口。
- 条目操作只有：播放、下载、删除、收藏、重新生成（确认弹窗）；**必须显示提示词与真实费用**。
- 不做「调色/配乐/进剪辑台」快捷按钮（用户明确要求删掉这些多余入口）；编辑一律去剪辑台。
- 剪辑台素材栏要能选：成片 / 片段 / 图片（图片首版可后置）；成片默认整段载入，保留“从成片重建工程”。
- 配乐库并入剪辑台配乐面板（试听、上传、删除、默认曲目）。
- 历史记录 / 产出入口最终下线；失败任务靠“库里失败可见 + 成片未完成卡片”，不再靠历史页。
- 气泡导航 4 项：创作 / 剪辑 / 库 / 设置（可收起；回收站放库页内）。

**删除与保留**
- 删除两步：移入回收站（可恢复）→ 再确认彻底删除；回收站不自动过期。
- 任何产物保留：片段有文件就入库（含质检失败）；mock 产物不入正式库。
- 历史任务没有费用快照时显示“未知”，不得伪装 ¥0。

**小智（后续阶段）**
- 改名**小智**（只改显示名与文案；代码标识不动），定位“管家 + 操纵者”，性格活泼但严谨。
- 方案 C：模型只负责「听懂 + 填计划卡」；执行/失败处理由确定性状态机做，不问模型。
- 记忆：会话内 + 任务检索（“上一次视频”用检索，不靠模型回忆）；跨会话偏好第二阶段。
- 语音：离线 ASR（已装）+ 失败回退打字。
- 失败处理：质检最多自动重试 **2 次** → 从片段库**补位**（按 ΔE76+SSIM 选最像、必须满足时长、不循环不慢放、补位率 ≤5% 且 ≤10 段）→ 仍不行才问用户；**不换备用模型**；单任务重试费用 ≤ 总预算 10%。
- 预算示例：30 分钟 720p = ¥1080；10% = ¥108；10s 一段 = ¥6/次。
- 成功率口径：**端到端最终 ≥99.9%**；不承诺“99.99% 一次成功”（数学上不成立）。
- 时长：用户给总时长（无默认）+ 每段时长；上限 60 分钟或 400 段取先到者；每段范围按模型（dashscope 2–30、kling 3–15、seedance ≤15）。
- 场景卡：v3.3 为唯一输入；不放回、按 chapter+sequence；失败用 buffer 替换；`promptComposer` 运行时拼 image/video 提示词，不写回卡；`palette_id` 用参数化调色（不引入 LUT）。
- **30 分钟上限**：卡库只有 180 张正片（10s/张），超过 30 分钟必须扩卡库（后续 A），当前先限制。
