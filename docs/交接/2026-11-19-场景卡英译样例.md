## 1. 数据格式（提案）

在每张卡里**追加**英文字段，不删不改中文字段：

```json
{
  "id": "sc-086",
  "protagonist": "湾口沙坝",
  "protagonist_en": "bay-mouth bar",
  "feature": "沙洲的湿沙分汊、风纹与水面反光",
  "feature_en": "braided wet channels across the sandbar, wind ripples, and specular reflections on standing water"
}
```

要加的字段（16 个，都是会进 prompt 或界面显示的）：

`biome_en` `landform_en` `feature_en` `foreground_en` `weather_en` `season_en` `light_en`
`shot_en` `cameraAngle_en` `lens_en` `motion_en` `palette_en` `highlight_control_en`
`protagonist_en` `avoid_en` `end_lock_en`

**不加**的：`science.*`（后台审查用，不显示）、`chapter/sequence/id`（机器字段）、
`style/palette_id`（受控枚举，由模板映射）。

## 4. 真实拼装结果（用现有模板跑出来的，不是我手写的）

**sc-086 / en**：

> Subject: bay-mouth bar; braided wet channels across the sandbar, wind ripples, and specular reflections on standing water. Foreground: sandbar grass. Camera: extreme wide shot, ground-level wide angle, 28mm, motion: static / locked-off. light: cool grey light; light direction: ambient; weather: post-storm clearing; season: autumn. palette: cool blue with warm rim light; look: cinematic calm tone (low saturation, fine tonal layers, stable composition). water and wet-sand highlights must not clip to white; shadows keep tonal separation. Ending: frame locks off; nothing new enters.

**关键点**：整段**零中文**，且句式、顺序、`look:` 映射全部来自现有模板 —— 说明只要加 `_en` 字段，出片提示词立刻变英文。

顺带发现两个小的格式问题（不影响正确性，可顺手修）：
- `light:` / `look:` 首字母小写，与前文 `Camera:` 风格不一致；
- `light direction: ambient` 来自 `light_azimuth`，该字段没有 `_en`，目前是原值（恰好是英文单词，但换成中文值就会漏）。

## 5. 审校要点（这些词最容易翻错，请你重点看）

| 中文 | 为什么难 | 我的处理 |
|---|---|---|
| 沙洲 / 湾口沙坝 | sandbar 是通用词，bar/barrier bar 有地貌学区别 | protagonist 用 bay-mouth bar（更具体），landform 用 sandbar |
| 湿沙分汊 | 中文是"分汊的水道" | braided wet channels（braided 是地貌术语，比 "branched" 准） |
| 风纹 | 沙丘风纹有专业词 | wind ripples（不用 sand lines） |
| 滑落面 | 沙丘背风面的标准术语 | slip face |
| 沙粒反光 | 颗粒级的镜面反光 | grain-level specular glints |
| 不炸白 | 摄影圈黑话=高光不削顶 | must not clip to white |
| 暗部保留层次 | | shadows keep tonal separation |
| 画面锁死 | 结尾不能有新元素 | frame locks off; nothing new enters |
| 点景 | 主体极小、点在大景里 | dot-in-landscape（附英文解释，避免模型不懂） |
