## 1. 负向提示词仍中文（差 1 行接线）

**现状（实测）**：`composeClipPatch(card, {lang:'en'})` 的 `negativePrompt` 200/200 张含中文。
原因：`src/promptComposer.js:270` 无条件走 `_negative(card)`（只读中文 `negative/avoid/science.forbidden`）。

**已就绪**：
- `src/i18n/templates/scene.js` 的 `negativeEn(card)` 已改成**只取 `*_en`**（`negative_en` + `avoid_en` 去 `no ` 前缀 + `science.forbidden_en`；无 `_en` 时用通用英文兜底）。
- 数据已加 `negative_en`（1 种值 ×200）+ `card.science.forbidden_en`（7 种值 ×200）。

**待 Lead 改（1 行，`src/promptComposer.js:270`）**：

```js
// 原
const negativePrompt = _negative(card);
// 改
const negativePrompt = _isEn(ctx.lang) ? sceneTemplates.negativeEn(card) : _negative(card);
```

中文分支不变（`_isEn` 只在 `lang=en*` 为真）；改完中文 `negativePrompt` 与改动前逐字相同。

**验收**：

## 2. 场景卡预览接口仍返回中文提示词（1 行 + 1 个显示字段）

**现状（实测）**：`server.js` 的 `GET /api/scene-cards/preview` 调 `composeClipPatch(card, {})`，
没传 lang；且返回的 `sceneKey` 是中文，被 `web/src/screens/createSmart.js:326` 直接显示。

**服务端已有 `req.lang`**（`server.js` 的中间件：cookie `vs_lang` → Accept-Language → zh），
所以**不用改 web**：

```js
// server.js：/api/scene-cards/preview
const patch = promptComposer.composeClipPatch(card, { lang: req.lang });
return {
  // ...
  sceneKey: req.lang === 'en'
    ? (card.protagonist_en || card.scene_key)   // 英文界面显示英文名
    : card.scene_key,
  // 可选：保留原键便于审计
  sceneKeyZh: card.scene_key,
  // ...
};
```

**验收（需用户重启 3001 后）**：
```powershell
# 用 vs_lang=en 登录态请求，返回的 prompt/imagePrompt 不含 [\u4e00-\u9fff]
# 用 vs_lang=zh 请求，中文与改动前逐字相同（可用 git show HEAD:... 对照）
```

> 注意：本接口是“看场景卡”预览，不建任务、不持久化；**不要**为验证它去真跑出图/出视频。

## 3. 助手“你选了哪些场景”仍显示中文卡名

**现状（实测）**：`src/assistant/supervisor.js:384 sceneCardLine` 硬读中文字段
（`scene_key / biome / landform / shot / palette` + `第 X 章` + `缓冲卡`）；
英文分支 `:1409` 也调它，所以英文聊天里会出现中文。

**patch 思路**（约 20 行）：
- `sceneCardLine(entry, i, lang)` / `formatSceneEntries(entries, lang)` 增加 `lang` 参数；
- 英文：名称用 `card.protagonist_en || card.scene_key`；标签用
  `biome_en / landform_en / shot_en / palette_en`；章节 `ch. ${chapter}-${sequence}`；缓冲 `buffer card`；
- 调用点传当前分支的 `lang`/`isEn`：`supervisor.js:464, 484, 488, 1351, 1409, 1413`（以当前文件行号为准）。

**验收**：英文会话里问“选的是哪三个场景”，回复的卡名/标签零 `[\u4e00-\u9fff]`；
中文会话与改动前逐字相同（`verify-assistant.js` 必须保持 263/0）。
