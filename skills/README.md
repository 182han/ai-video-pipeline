# skills/ — 项目自研的 AI 助手技能（研发沉淀，非运行时依赖）

> 2026-11-13 加入。来源：本项目开发过程中在同一台机器上磨出来的 agent skill，
> 由项目作者编写，随项目一起交付，方便接手的团队复用同样的方法论。

## 这里面有什么

| 目录 | 用途 | 与本项目的关系 |
|---|---|---|
| `fengguang/` | 「摄影级自然风光视频提示词」技能：把一句人话写成可直接投喂文生视频模型的中文提示词（含两档风格、三套色板、10 条自检卡、地貌专名表、极光四型、片源筛选） | **直接服务本项目的核心场景**。运行时程序并不读取这个目录，而是读取 `data/skill-fengguang.rules.md`（从本技能抽取的叠加规则 v0.2.6）；本目录是完整版，含参考资料与工具 |
| `changrenwu/` | 「长任务 · Agent 双阶段工作流」：上下文快满 / 换窗口 / 新窗口接手 / 两个窗口撞车时的操作规范 | 本项目开发过程中的协作经验沉淀（换窗口交接、避免并发覆盖），对继续维护本项目有用 |

## 重要：这两个目录不是运行时依赖

- 删掉 `skills/` 不影响程序启动与功能；
- 程序真正使用提示词规则的地方是 `data/skill-fengguang.rules.md`（由 `src/promptSkill.js` 加载）；
- 想改规则：改 `data/skill-fengguang.rules.md` 即可，无需重启逻辑，下次调用自动读到。
