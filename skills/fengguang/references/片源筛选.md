## 0. 三条判据（与提示词判据完全不同）

提示词判"写得像不像摄影"，片源判"**放不放得住**"。三件事同时成立才算合格：

| 判据 | 问什么 | 不合格的信号 |
|---|---|---|
| **真** | 是原生拍摄，还是搬运 / 超分 / 复刻？ | 简介空、只有 YouTube 链接、8K 但暗场糊、画面和某部官方屏保一模一样 |
| **净** | 画面里有没有"不属于景的字"？ | 水印、烧录字幕、章节标题卡、照片标注小字 |
| **耐** | 慢不慢、切不切、结尾能不能接回开头？ | 10 秒一切、每个镜头都换机位、片尾出 logo |

三条缺一条**不是不合格，是降档**：**A** 可直接用（按片长当主片或插播）·
**B** 有条件可用（切段、静音、仅私人）· **C** 慎用（有硬伤）。

## 1. 四问定档

**问 1：来源是哪一档？**（画质与风险都由它决定）

| 档 | 特征 | 后果 |
|---|---|---|
| 原生实拍 | 摄影师/机构原片，有拍摄信息 | 暗场干净，可放到最大 |
| 摄影师照片流 | 一张张原始照片做延时/平移 | 细节极好，但常带标注小字 |
| 搬运 | 简介给外链、来源不明 | 画质不可控，版权风险高 |
| 超分 | "8K 修复""AI 增强"，素材来自别处 | 暗场有涂抹感，星点会糊成团 |
| 复刻 | 照抄某官方屏保（如 macOS Sonoma） | 不是实拍，版权归原厂 |

**问 2：画面里有字吗？** 有字就进不了 A 档——屏保是"没人看屏幕时"的画面，
任何文字都会在余光里变成噪点。四条见 §2。

**问 3：节奏？** 屏保要"慢到可以走神"。平均镜头时长 < 20 s（经验值）的，定位通常是"屏幕测试片"，
不是屏保；可以留着测电视，但别当主片。

**问 4：时长与接缝？** <10 min 必须自己算循环点；30–60 min 靠播放器循环；
>120 min 基本不用管循环，但**开头 30 s 要能直接进画面**（不能先是黑屏/台标/标题）。

## 2. 五个「屏保杀手」

| 杀手 | 为什么致命 | 30 秒内怎么发现 |
|---|---|---|
| **画面水印**（DJI / 8KRAW / 台标） | 固定位置的半透明字，比字幕更显眼 | 看四角，尤其左下/右下 |
| **章节标题卡** | 每章开头 2–3 s 满屏粉字，循环时会反复撞上 | 拖到章节切换处（简介里的时间点） |
| **照片标注小字** | 天体编号、曝光时长，静帧里是自豪，屏保里是噪点 | 看照片右下角 |
| **烧录字幕 / 口播** | 有人声就得关声音，关了又失去一半氛围 | 看底部 1/5，听前 15 s |
| **快切蒙太奇** | 屏保最怕"有节奏"，余光会被拽走 | 数十秒内切了几个镜头 |

另有两个**非文字**杀手，容易被忽略：

- **非 16:9**（这批里就有 3840×2026、3840×1920、3840×1770、4096×2160 四种）：电视上要么黑边，要么被裁。
  核验时看分辨率是否严格 16:9——**标"4K"不等于 16:9**。
- **HDR 源接 SDR 屏**：可能整体发灰、暗部抬升。**必须在自己电视上实测 30 秒**，不能只看标称。

## 3. 分辨率 ≠ 清晰度

这是选片最容易交的学费。4K/8K 是**上传规格**，落到眼睛里的是"码率 + 压缩 + 源素材"。

| 现象 | 真因 | 判据 |
|---|---|---|
| 标 4K 但暗场一团块 | 平台二压，暗场码率不够 | 暂停在星空/极光暗部，看有没有成片的方块（压缩宏块） |
| 标 8K 但星星是糊团 | AI 超分把点光源抹成斑 | 星点应是"点"，不是"雾" |
| 标 8K 但运动拖影 | 帧率/快门不对，不是分辨率问题 | 看流水、云边 |
| 1080p 电视上反而更"干净" | 降采样同时抹掉了细节和二压噪点 | 但严重块状/拖影仍在，别指望它救片 |

**结论**：4K 电视优先原生 4K；1080p 电视上 4K 的优势会被降采样抹平，**不必为 8K 付费**；
OLED 上暗场块会被放大，极光/星空段尤其要挑原生高码率。

## 4. 设备矩阵（4K / 1080p × 有声 / 静音）

| | **有声** | **静音** |
|---|---|---|
| **4K 电视** | 原生 4K 实拍 + 轻配乐长片（奥地利类）；避开超分与水印；极光/星空选原生高码率 | 画面干净度优先；自然声片静音也不亏；适合"关机前 20 分钟" |
| **1080p 电视** | 4K 源够用，别追 8K；配乐密度低的优先（3 小时循环，配乐太满会腻） | 最宽松的一格：只剩"有没有字"和"切得慢不慢"两个变量 |

两条补充：

- **声音是"耐不耐放"的隐藏变量**。3 小时循环同一段配乐，很容易腻；自然声（浪/风/鸟）耐受度最高，
  但深夜/卧室仍建议静音——屏保的第一功能是"不打扰"。
- **观看距离决定分辨率收益**。3 m 看 65 寸，1080p 与 4K 的差距远小于"有没有水印"的差距。
  先解决字，再谈像素。

## 5. 时长决定要不要做循环

| 片长 | 循环策略 | 检查点 |
|---|---|---|
| <10 min | 自己做首尾淡化（xfade），或干脆不循环、放进播放列表 | 回绕帧 SSIM（参考本项目 `checkLoop`，阈值 0.9） |
| 30–60 min | 播放器单曲循环 | 片尾最后 5 s 是否停在稳定画面上 |
| >120 min | 不用循环 | 开头 30 s 能否直接进画面 |

**接缝三级**：段内切点（同一支片里的转场）→ 片间切换（播放列表）→ 回绕点（首尾相接）。
屏保的"高级感"很大一部分来自第二级：两条片之间用 0.4 s 交叉淡化，比任何单条片都值钱。

## 6. 版权三档（只说结论，不说教）

| 档 | 例子 | 能做什么 |
|---|---|---|
| 原创摄影师 / 机构 | CC-Chen、8KRAW | 私人观看没问题；**商用要单独授权** |
| 搬运号 / 来源不明 | 简介给 YouTube 链接、简介为空 | 私人观看风险自担；**别二次上传** |
| 版权方素材复刻 | macOS Sonoma 屏保复刻 | 画面版权归原厂，**别当素材用** |

一句话：**别下载再上传、别商用、别当自己作品发**。个人在家当屏保，属于私人观看。

## 8. 五条可迁移结论（比片单重要）

1. **同一批素材，"机构号"版常带水印，"器材厂商样片"版反而干净。** 挑片时先搜同素材的另一版。
2. **章节结构 = 标题卡 = 屏保杀手。** 所以"两小时相册电影"要按章节切段用，不能整条挂机。
3. **最"高级"的不是最长的，而是循环点干净的短片。** 长片解决"不想管"，短片解决"开机那几分钟"。
4. **照片标注小字是作者的自豪，不是屏保的资产。** 作者的表达目标和屏保屏的目标不是一回事，
   选片一律按后者判。
5. **先解决"字"，再谈"像素"。** 一条 1080p 无水印的片，观感通常好过一条 8K 带水印的片。

## 9. 自己 30 秒验一条（可复述）

1. **先查元信息**：`https://api.bilibili.com/x/web-interface/view?bvid=<BV>`，看
   `data.dimension.width×height` 与 `data.duration`。**标"4K/8K"≠ 16:9 ≠ 真清晰**，只认宽高比与码率。
2. **抽四帧**：`0:05` / 中段任意 / 片尾前 10 s / 简介里标的章节切换点。
3. **看四件事**：四角有没有字、暗场有没有块、几秒切一次、结尾能不能接回开头。
4. **B 站取帧**：官方逐帧缩略图接口（`x/player/videoshot`），本 skill 的
   `tools/bilibili_sprite.js` 已封好（**偶发返回 0 帧时会自动换 `aid` 重试**）；
   或直接拖进度条，**关弹幕、关字幕**。
5. **落结论**：A / B / C + 一句"杀手是什么"。**没取到画面就写"未核验"，不要猜。**

> 判定三态与项目验收口径一致：**通过 / 不通过 / 未验证**。
> 把"未验证"写成"通过"，是这类片单最常见的错误。

## 11. 另一种用途：当训练语料

同一批片子，换个判据就变成语料。屏保看「放不放得住」，语料看「**拆不拆得开**」：

| 语料判据（四问全过才收） | 不合格的信号 |
|---|---|
| 地貌能命名 | 只能说"山/水/风景" |
| 光能指方位 | 只有"光线很美" |
| 机位与运动是一条主轴 | 两个运动/甩镜 |
| 画面里的字已标出（overlay） | 台标、地名、水印、章节卡没标 |

**三个不同点**：

- 屏保怕"字"，语料**不怕字但要标**——带台标的片子也能当负样本（训练"识别并剔除"）。
- 屏保要长、要慢；语料只要**一个能拆干净的 5–15 s 片段**。
- 屏保判分辨率够不够；语料判**证据够不够**：sprite 能判地貌与光，判不了焦段。

完整字段、反拆六步、抽查案例、入库三态与 1→4 扩写见 `references/语料规范.md`。
