# 摄影级自然风光视频提示词

## 何时使用

要写「自然风光 / 户外 / 星空 / 极光」类视频提示词，且要求达到**摄影级**而非图库级。

也用于反方向的问题：**手头这条现成视频能不能当电视屏保**（§十五，判据完全不同）。

还可以再反一次：把**已核验的画面拆成字段与提示词对**，做训练语料（§十六）。

也用于**改已有提示词**：换运镜 / 换光 / 换焦段时，一次只动一个维度（§十七）。

不适用：人像、城市街拍、剧情片；也不用于剪辑与配乐。

## 一、什么叫"摄影级"：三条判据

摄影级 ≠ 多写几个 `4K cinematic epic`。它是三件事同时成立：

1. **地貌可命名**——观众能说出"丹霞 / 雅丹 / 冰碛湖 / 沙丘脊线"，而不是"一片山"。
2. **光能指方位**——能指出光源在哪、影调往哪走。摄影是光的形状，不是景的形状。
3. **信息量被压住**——只留一个主角，其余主动让位。图库感的本质是"什么都好看、什么都不突出"。

**实测依据**（80 张静帧 + 2210 帧长片，见 `references/风格指纹.md`）：专业风光片的平均亮度稳定在 **104–105**，暗部 **9–16%**，**高光中位数仅 0.2%–3.4%**。也就是说——**"高光控死"才是摄影级的最硬特征**，比任何形容词都硬。

## 二、硬约束（先过闸）

| 项 | 约束 |
|---|---|
| 画幅 | 16:9 |
| 单段时长 | 5–15 s |
| 人物 | 默认零人物；**允许极小点景**（占画面 <2%，仅作尺度参照，不成为主体） |
| 镜头 | 一条慢运动主轴；禁止甩镜、变焦冲击、快速剪辑 |
| 循环 | 结尾不得引入新元素 |
| 一致性 | 同批素材固定 lens family + 同一套色板 |

## 三、两档风格（数据证明色板不同，必须分开写）

| | `dramatic`（比赛级戏剧感） | `cinematic-calm`（长片耐看感） |
|---|---|---|
| 亮度目标 | 95–105 | 105–115 |
| 饱和度目标 | **0.38–0.42** | **0.24–0.34** |
| 暖色像素 | 20–30% | 3–16% |
| 典型来源 | 用户的 80 张静帧（实测 sat 0.386） | Scenic Relaxation 长片（实测 sat 0.317） |
| 用在哪 | 单条封面、集锦高潮段 | 30 分钟屏保的主体 |

**混排比例**：`cinematic-calm` 7 : `dramatic` 3。全 calm 会闷，全 dramatic 会吵（长片实测暖主导帧仅 32%，静帧 40%）。

## 四、两条投喂路径（最容易错，别混）

**A. 走项目模板优化——只写「主体句」**

`promptOptimizer.optimizeWithTemplate()` 会自动追加 `运镜 + 光影 + 氛围 + 全量质感 + 结尾留白`。

所以主体句里**不要**再写：

- ❌ `4K` `cinematic` `film grain`（`quality` 池是**全量**拼的，会重复 6 次）
- ❌ `no people` `nothing enters frame`（`endingPool` 会追加）
- ❌ 第二套运镜/光影（会和池里选中的打架）

**B. 裸投喂生成器（直连可灵/即梦/万相，或经 AI 改写）——写全七段**

```
主体句（地貌专名 + 材质）
→ 运动（自然元素，慢）
→ 运镜（一种 + 焦段）
→ 光线（时刻 + 方位 + 冷暖）
→ 氛围（空气感/天气）
→ 质感（调色 + 颗粒 + 对比）
→ 结尾留白（锁死画面）
```

## 五、七段骨架与模板池对照

| 段 | 写什么 | 走 A 时是否要写 |
|---|---|---|
| 主体句 | 地貌专名 + 决定性材质 | ✅ 只写这段 |
| 运动 | 云/雾/水/雪/沙的自然位移 | ❌ |
| 运镜 | 一种主轴 + 焦段 | ❌ |
| 光线 | 时刻 + 方位 + 冷暖 | ❌ |
| 氛围 | 一句话情绪与空气 | ❌ |
| 质感 | 调色 + 颗粒 + 对比 | ❌（全量追加） |
| 结尾 | 留白句 | ❌ |

## 六、用户说人话，skill 补专名

**绝不要求用户懂术语。** 用户说"沙漠"，你就翻译成"沙丘脊线 + 迎风坡风纹 + 背风滑落面"。

| 用户随口说 | 翻译成 | 为什么必须换 |
|---|---|---|
| 沙漠 | 沙丘脊线 / 风纹 / 滑落面 | "沙漠"只会得到通用沙海；脊线才有那条亮暗分界的刃 |
| 红色的山 | 丹霞赤壁，层理状红色砂砾岩 | 不说层理，模型会画成一块红塑料 |
| 石头山 | 喀斯特峰林 / 锥形孤峰 | 不说形状，模型给圆包 |
| 雪山 | 冰川舌 / 冰碛湖 / 粒雪原 | 不说部位，模型给一堆白尖尖 |
| 石头乱插在地上 | 石林 / 雅丹土丘 | — |

完整 50 条对照表见 `references/词库.md` §1。

## 七、构图五条

1. **一个主角。** 写不出"主角是什么"就还没写完。
2. **三层纵深。** 前景压角（苔石/沙脊/灌木剪影）→ 中景主体 → 远景空气层。缺前景立刻变图库。
3. **负空间 ≥ 40%**，且要有渐变（不是死白）。
4. **尺度锚点。** 需要尺感时放一个 <2% 的点景（人影/船/羊/帐），不居中、不与主体抢。不需要时用**纹理尺度**替代（一道沙纹就是一个尺度）。
5. **一条线。** 地平线/脊线/河曲/田垄分割画面；非刻意对称时**不与画框平行**。
6. **纹理特写**：贴面或俯拍，侧光切出纹理，**画面里不给天空**。成片 15% 靠它，写成"一张风景"就废。

> ⚠️ **3:2 → 16:9 重构图**：参考图多为 3:2 静帧，直接套 16:9 会让三分点上移、天空比例失控。写提示词时明确"地平线在画面上 1/3 或下 1/3"，不要留空。

## 八、光线时刻表（选一个，不叠加）

| 时刻 | 影调 | 关键词 |
|---|---|---|
| 日出前 30 min | 冷蓝平稳，适合长曝 | blue hour, cold cyan ambient, glassy stillness |
| 日出/日落 0–10 min | 侧逆光、金边、长影 | golden hour, rim light, long soft shadows |
| 太阳贴地平 | 大光比剪影 | sun disc, silhouetted ridges, extreme contrast |
| 日照金山 | 峰顶粉金 vs 山谷冷蓝 | alpenglow, warm summit, cold blue valley |
| 日落后 20 min | 青蓝天 + 稀缺暖点 | afterglow, teal sky, single warm point |
| 无月夜 | 银河拱桥 | moonless night, galactic arch, faint zodiacal glow |
| 极光夜 | 帘幕拖尾 | aurora curtains, long-exposure trail |
| 阴天散射 | 低反差、显纹理 | soft overcast, even light, saturated detail |
| 狭缝漏光 | 一束天光从窄缝落下，岩壁明暗两分 | slot light, single shaft, near-black shadows |
| 侧光切层理 | 低角度侧光横切层理，纹理立体 | raking side light, bedding relief |
| 顶光偏平 | 无长影，靠层理自身分色 | flat overhead light, tonal separation only |
| 蓝调散射 | 日出前/日落后，冷蓝无方向光 | blue-hour ambient, directionless |
| 月光三档 | 无月 / 有月 / 月升，决定星点与极光亮度 | moonless / moonlit / moonrise |

加分光：`god rays through cloud gaps`、`brocken spectre`、`rain shaft`。

> **阴天散射没有方向**，必须补一句光源在哪（云层哪侧更亮 / 天光从海面反上来），
> 否则"光位"这一项等于没写——模型会给一片均匀灰。

## 九、三套色板（实测校准，按题材选一套）

| 色板 | 适用 | 亮度 | 饱和 | 冷暖配比 | 英文写法 |
|---|---|---|---|---|---|
| **极冷极淡** | 国家地理式大景、冰川、雪原、雾 | 108–114 | 0.22–0.26 | 冷 60% / 暖 3% | `near-monochrome cold palette, cyan-grey shadows, almost no warm accent` |
| **暖浓** | 秋色、丹霞、沙丘、日落 | 112–120 | 0.36–0.40 | 冷 28% / 暖 32% | `rich warm palette, ochre and rust, cool shadow separation` |
| **暗底暖星云** | 银河、星云、极光 | 75–85 | 0.28–0.31 | 暗 27% / 暖 36% | `deep dark base, luminous warm nebula, magenta and teal` |

三套都必须带 `controlled highlights, no blown-out sky`。实测长片高光中位 0.2%，**过曝天空是最常见的失败**。

## 十、镜头配比与节奏（30 分钟成片用）

| 类型 | 占比 | 作用 |
|---|---|---|
| 大全景航拍 | 40% | 交代地貌格局 |
| 中景地貌 | 25% | 主体与光 |
| 纹理特写 | 15% | 沙纹/冰裂/岩层，提升"贵感" |
| 生物或点景 | 10% | 鲸/鸟/羊/船，提供尺度与生气 |
| 天文 | 10% | 银河/星轨，做夜段 |

**节奏**：一段壮（全景）→ 一段净（特写/极简）交替，禁止连续三段同类型。

**纹理特写**按 §七 第 6 条写：贴面/俯拍 + 侧光切纹理 + 不给天空
（`gl-01` 冰碛砾石、`tx-02` 层理、`tx-05` 冰裂都是这个语法）。

## 十一、天文四子类（语法完全不同）

| 子类 | 画面 | 提示词要点 |
|---|---|---|
| 深空星云特写 | 粉红/青金星云，无地景 | 望远镜视感、无地平线、`deep-sky nebula field, no horizon` |
| 银河拱桥 | 银河横跨 + 地景剪影 | `14mm ultra-wide, galactic arch, foreground silhouette` |
| 星轨同心圆 | 长曝弧线绕天极 | `star trails, concentric arcs around the pole, static tripod`（**必须固定机位**，不配推轨/横移） |
| 极光 | 见下表，按**形态 + 前景**分 | 别按"颜色"分 |

**极光：四型 × 三前景**（据 2026-10-27 片源观察整理）

| 形态 | 画面 | 提示词要点 |
|---|---|---|
| 极光弧 | 一条绿弧横跨天顶，边缘洋红 | `auroral arc spanning the sky, oxygen green with magenta fringe` |
| 帘幕 | 竖直光帘/拖尾，缓慢波动 | `aurora curtains, vertical rays, slow undulation` |
| 贴地辉光 | 贴着地平线的绿光带，不占满天空 | `ground-hugging green glow above the horizon` |
| 冠冕 | 天顶辐射状，需超广角/鱼眼 | `auroral corona at zenith, wide-angle` |

前景三选一：**雪林剪影**（最稳）· **无风湖面倒影**（对称，靠水面）·
**海岸线 + 小镇灯火**（唯一的暖点，用来压住满屏绿）。

⚠️ **不要写"紫雾满天"**：模型会把极光画成紫烟。极光主体是**氧原子绿**（557.7 nm），
洋红只出现在边缘和强活动时。

## 十二、自检卡（10 条全过才投喂）

1. 能一句话说出**主角**？
2. 能指出**光源方位**？
3. 用了**地貌专名**（不是"山/水/风景"）？
4. 明确选了 `dramatic` 或 `cinematic-calm`？
5. 色板与题材匹配（§九）？
6. 有**前景**、负空间够大？
7. 只有**一条**运动主轴？
8. 结尾**不引入新元素**？
9. 写了 `controlled highlights, no blown-out sky`？
10. 没混入会被模板重复追加的词（`4K`/`cinematic`/`no people`）？

## 十三、失败对照表

| 症状 | 真因 | 改法 |
|---|---|---|
| 图库感 | 要素都好看，无主角 | 砍一半元素，指定唯一主角 |
| 塑料/HDR 味 | 堆 `4K 8K ultra detailed hyperrealistic` | 只留 `cinematic grade + film grain + natural contrast` |
| 天空死白 | 没写高光控制 | 加 `controlled highlights, no blown-out sky` |
| 山形乱变 | 没说地貌类型 | 换专名（锥形孤峰/danxia/yardang/karst pinnacle） |
| 镜头飘 | 写了两个运动 | 一条镜头主轴 + 一个自然元素运动 |
| 循环断 | 结尾引入新主体 | 结尾锁死 `nothing enters frame` |
| 同批不统一 | 每段换镜头/色板 | 固定 lens family + 一套色板 |
| 出现人物 | 只在正文写 no people | 正文 + `negative_prompt` 双写 |
| 像明信片 | 信息量太大、太全 | 换 `cinematic-calm`，砍到单一主体 |
| 像壁纸没记忆点 | 太净、无锚点 | 加一个尺度锚点或一道决定性光 |
| 极光像紫烟 | 只写 aurora + 紫色形容词 | 主语改 `oxygen green`，洋红只写 `fringe`；再补形态（arc / curtain） |
| 焦段与机位族错配 | 200mm 换成 16mm、望远镜当广角 | 先定机位族，再从 §十七 的焦段池选 |
| 静机位配推镜 | 静机位 + 缓推/摇臂/升降 | 固定机位只做"微转/不动"；要升降就删"静机位" |
| 极光形态与光位打架 | 帘幕 + "只压地平线" | 按 `aurora_type` 选光（§十一） |
| 月夜自相矛盾 | 无月夜 + 月光照海面 | 换光时同步改氛围句（月光→星光） |
| 纹理拍成风景 | 有天空、无侧光 | 贴面/俯拍，侧光切纹理，不给天空 |
| 换光后"光斑还在移动" | motion 是原光位的产物（光斑/光柱/日照推进/月光） | 该组换光 N/A，不生成；不许联动改 motion |

> 完整成品范例（雪山 / 沙丘 / 银河 / 深空星云 / 秋色，共 5 条 + 1 组反例改法 + 批量差异化技巧）见 `examples/样例.md`。

## 十五、片源筛选：现成的片子能不能当屏保

本 skill 默认「生成」。但电视屏保还有另一条更省的路：**用现成成片**。判据完全不同——
提示词判"写得像不像摄影"，片源判"**放不放得住**"。

三关，缺一降档：

1. **真**：原生实拍 > 摄影师照片流 > 搬运 > AI 超分 > 复刻（如 macOS 屏保）。
   超分会把星点抹成雾，复刻根本不是实拍。
2. **净**：画面里不能有"不属于景的字"——水印、烧录字幕/口播、章节标题卡、照片标注小字。
3. **耐**：慢、少切、结尾不引入新元素。<10 min 要自己算循环点；>2 h 靠播放器，
   开头 30 s 要能直接进画面。

**分辨率 ≠ 清晰度**：4K/8K 是上传规格，二压后的暗场块与拖影才是实际观感。
1080p 电视上 4K 的优势会被降采样抹平，不必为 8K 付费；OLED 上暗场块会被放大。

**版权三档**：原创摄影师（商用要授权）/ 搬运号（私人看、别二次上传）/ 版权方复刻（别当素材）。

完整流程、设备矩阵（4K/1080p × 有声/静音）、22 条案例与「30 秒验证法」见
`references/片源筛选.md`。

## 十六、反向：画面 → 提示词（语料）

前十五节都是「人话 → 提示词」。反方向同样成立，而且能造训练集：
**已核验画面 → 字段 → 提示词**。判据换成「**可拆性**」四条——
地貌能命名、光能指方位、机位与运动是一条主轴、画面里的字已经标出来。

字段固定 17 个（`id / src / t / place / theme / landform / light / camera / motion /
atmosphere / lock / palette / grade / overlay / overlay_note / frame_source / prompt`），
v0.2 再加 `verified / inferred / negative / aurora_type / foreground / note`。

三条不能省的纪律：

1. **sprite 能判地貌与光，判不了焦段。** `24mm / 50mm` 是推断值，必须写进 `inferred`。
2. **取到帧 ≠ 看过帧。** `verified=true` 只能由看过画面的人写，`frame_source` 有值不算。
3. **没看过就标未核验。** 不许用"同题材规律"补齐字段——那是在教模型编。

**扩写集**（`variant_of` + `changed`）只能改一个维度：`camera-move` 只动运镜、
`light-azimuth` 只动光、`lens` 只动焦段。`camera` 要拆成「焦段 / 机位+运镜」两半分别比——
不拆就发现不了"换光时顺手改了机位"和"静机位 + 缓推"这类双主轴。
切 train/eval 必须**按 `variant_of` 分组**，同组的 base 与变体不许跨集。

抽查方法、入库三态、1→4 扩写、污染源与体检脚本见 `references/语料规范.md`；
批量检查：`node tools/check_corpus.js <corpus.jsonl> --variants <variants.jsonl>`。

## 十七、改一条提示词：单维度改写

写新词是一半，另一半是**改已有的**：同一场景换运镜 / 换光 / 换焦段。
原则只有一条：**一次只动一个维度，主体句和结尾锁句逐字不动**。

| 维度 | 可改 | 不许 |
|---|---|---|
| 运镜 | 只替换运镜词（整词）：缓推 / 横移 / 升镜 / 静机位微转 / 沿崖横切… | FPV 不许配「缓推」；静机位不许配推/横移；星轨必须固定 |
| 光线 | 同题材光池内换：侧逆 / 阴天散射 / 蓝调 / 正午… | 极光/星空不许换正午；主体句有「月光」的不许换「无月夜」；帘幕不配「只压地平线」 |
| 焦段 | 同一机位族内换（见下表） | 长焦/望远镜不许换广角；换焦段不许顺手改运镜 |

**机位族 → 焦段池**（50 条 base + 129 条变体的实测）：

| 机位族 | 焦段池 |
|---|---|
| 航拍高位 / 中位 / 斜俯 | 24 / 28 / 35mm |
| 地面（平视 / 俯拍 / 低机位） | 14 / 16 / 20 / 24 / 35 / 50mm |
| 贴壁 / 狭缝 | 14–18mm，或 35mm 压缩壁面 |
| FPV | 16 / 18 / 20mm |
| 鱼眼全天 | 11mm |
| 长焦 / 望远镜 | 135 / 200 / 300 / 400 / 600 / 800mm |

**三条自检**：

1. 改完 diff：除目标字段外逐字相同；`camera` 要拆成「焦段 / 机位+运镜」两半分别比。
2. 新句与原句不打架：无月夜不能配月光，静机位不能配推镜，星轨不能配移动。
3. 主体句与结尾锁句没动——动了就不是变体，是新片段。

**换光前先查"光依赖"**：`motion` 或主体句里如果有**只属于原光位的现象**——
光斑（窄缝漏光）、光柱/云隙（god rays）、日照金山/光带自峰顶推进（alpenglow）、
月光/月影（月夜）、长影（低角度侧光）——这一组的换光就 **N/A**：跳过该维度，
**不许联动改 motion 或主体句**（改了就不是单维度）。

> 反例：`dx-02` 的 motion 是「光斑沿岩壁缓慢移动」；光一换成侧逆光，狭缝没了，光斑也不成立。

> 这套规则由 50 条 base + 129 条变体反推；程序化校验见 `references/语料规范.md` §7。

## 十八、多段连续性（5 段拼一条片）

单条好写，五条拼起来最容易"串味"。四条硬约束：

1. **运镜轮换**：5 段至少 4 种（静止 / 推进 / 横移 / 摇臂 / 环绕），相邻段不许同一种。
2. **静机位就真静**：静机位段里不许出现摇臂、升降、推轨、横移——
   "静机位 + 极慢摇臂升降" 自相矛盾（实测盲测就栽在这句）。
3. **光位按时序走**：阴天 → 太阳贴地平 → 蓝调 → 日落后 → 无月夜；一段一光，不重复。
4. **色板统一、暖点 ≤1 段**：五段共用一套色板；主体句不复用，每段各自锁画面。

一个可直接套的 5 段骨架（冰岛示例）：

| 段 | 主体 | 机位 / 运镜 | 光位 |
|---|---|---|---|
| 1 | 玄武岩黑沙滩 + 礁石平台 | 地面 35mm，静态锁定 | 阴天顶散射，云层最亮 |
| 2 | 垂海瀑布 + 苔藓崖壁 | 贴壁 24mm，极慢推进 | 太阳贴地平，右侧侧逆 |
| 3 | 冰川蓝冰 + 冰裂纹 | 45° 斜俯 24mm，极慢平移 | 蓝调散射，无硬影 |
| 4 | 海蚀柱 + 卵石滩 | 岸上 85mm，横向滑轨 | 日落后 20 分钟，左侧一线暖 |
| 5 | 极光帘幕 + 海蚀崖剪影 | 14mm，摇臂极慢升降（**不写静机位**） | 无月夜，氧绿为主 |

首尾可同色调、同机位，方便循环剪辑。

## 约束

- **不写无效形容**：`震撼 / 唯美 / 大片 / 绝美` 一律替换成具体物与光。
- **地貌名优先于形容词**：能写 `yardang` 就不写 `weird rock`。
- **一条提示词只允许一条运动主轴**。
- **默认尊重真实地理与季节**；超现实必须显式声明。
- **不承诺水印/字幕/转场**，那是流水线的事。
- **默认静音、不写分辨率**：提示词里不出现声音/配乐/音效，也不写 `4K/8K`——
  分辨率是上传规格，不是画面描述。
- 本 skill 产出提示词、片源判定与语料规程，不改代码。
